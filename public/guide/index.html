Meet ModuleTracker

Plan, script and track every VR module in one place.

ModuleTracker replaces the pile of planning docs and spreadsheets with one shared app. Three things make it different:

Module creation

Start with what the expert knows

A guided Discovery Form walks through the topic, learning objectives, tools, and each scene: who speaks, what's clicked, and the quiz questions. No blank page.

Scripting

The script sets itself up

One click turns the Discovery Form into a Google Doc laid out scene by scene, saved in a shared team folder, so everyone writes in the same copy.

Multiple views

See production your way

Every task as a List, a Board you drag cards across, or a Timeline. For one module, or all of them at once.

Good to know

  • Three tabs: Modules, Scripts and Tasks. The app name takes you back to the Dashboard.
  • Rough is fine. Everything in the Discovery Form can be edited later from the module's page.
  • One copy of each script lives in a shared Google Drive folder; the app links to it.
  • Nothing is lost: every change is recorded, can be undone, and is backed up automatically.
  • Works on phones too. Add the page to your home screen to open it like an app.
